**How did I turn dataflow facts into assertions?**
I added asserts for my dataflow facts by walking through the operations after analysis. I collected the different dataflow facts into vectors, then looped through them and added asserts. At first, I added asserts for all facts, but this triggered errors when statements were added in the global initializer, so I switched to adding asserts only inside functions.

  void add_asserts(ArrayRef<std::pair<Value, Operation *>> values,
                   LLVM::ICmpPredicate predicate, int64_t expected,
                   StringRef message) {
    for (auto [value, definingOp] : values) {
      OpBuilder builder(definingOp);
      builder.setInsertionPointAfter(definingOp);
      Location loc = definingOp->getLoc();
      Value expectedValue =
          LLVM::ConstantOp::create(builder, loc, value.getType(), expected);
      Value condition =
          LLVM::ICmpOp::create(builder, loc, predicate, value, expectedValue);

      std::string location;
      llvm::raw_string_ostream locationStream(location);
      loc.print(locationStream);
      locationStream.flush();
      cf::AssertOp::create(builder, loc, condition,
                           (message + " " + location).str());
    }
  }
